# 鸭子模型与物理环境实施计划

本文把“准备建立鸭子和物理环境”拆分为可执行任务。当前阶段只做模型和环境，不训练最终策略。

## 1. 前置依赖

建议先固定 Python 3.12，再安装以下依赖：

```bash
uv python pin 3.12
uv add mujoco gymnasium numpy tensorboard
uv add --dev pytest
```

说明：

- 当前仓库 `.python-version` 为 3.14，部分 RL/科学计算库可能尚未提供稳定轮子，建议先切换到 3.12。
- 训练阶段再安装 `stable-baselines3` 和 PyTorch。
- 安装完成后先运行最小 MuJoCo 加载测试，确认图形/离屏渲染环境可用。

## 6. 建议的调试顺序

1. 先让模型在零动作下站立 1 秒，观察是否抖动或穿模。
2. 手动给一个正弦动作或其他简单周期动作，确认关节符号正确。
3. 用随机动作测试奖励和终止逻辑，确保奖励不会因接触或除零产生 NaN。
4. 用非常短的 PPO 训练检查观测、动作维度和日志。
5. 最后才调奖励权重和训练时长。

## 7. 风险与应对

| 风险 | 表现 | 应对 |
| --- | --- | --- |
| 默认姿态脚底穿地 | 模型重置即触发倒地 | 调整躯干高度、腿长和脚掌位置 |
| 物理步长过大或执行器过强 | 抖动、爆炸、NaN | 减小 `sim_dt`，降低 `kp`，检查质量和惯性 |
| 自碰撞造成爆炸 | 膝盖/大腿接触异常 | 第一版关闭自碰撞，后续用 `exclude` 精细配置 |
| 观测尺度差异大 | PPO 训练不稳定 | 使用 VecNormalize，或手动缩放关节速度 |
| 奖励设计导致站立不动 | 总奖励高但速度为 0 | 加强速度跟踪，减小静态奖励，检查各项指标 |
| 鸭子只会“滑行” | 速度上去了但步态不自然 | 增加足底接触/步态项、动作平滑和摩擦测试 |
| 行走与奔跑界限不清 | 高速时仍用拖脚或跳跃 | 观察腾空比例和视频，调整速度指令和奖励 |

- 能输出 34 维观测、8 维动作、奖励分项和终止原因。
- 有一个可重复的短训练脚本，能生成模型文件和基础日志。
- 文档中的尺寸、关节名、维度与实际代码一致。
