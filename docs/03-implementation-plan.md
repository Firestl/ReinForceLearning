## 6. 风险与应对

| 风险 | 表现 | 应对 |
| --- | --- | --- |
| 默认姿态脚底穿地或悬空 | 模型重置即触发倒地或下坠 | 按 root≈0.233 m 与腿长核算，并加脚底高度测试 |
| 物理步长过大或执行器过强 | 抖动、爆炸、NaN | 减小 `sim_dt`，降低 `kp`，检查质量和惯性 |
| 自碰撞造成爆炸 | 膝盖/大腿接触异常 | 第一版用 `contype`/`conaffinity` 关闭鸭子自碰撞，仅保留鸭子-地面接触；后续需要时用 `exclude` 精细配置 |
| 观测尺度差异大 | PPO 训练不稳定 | 使用 VecNormalize，或手动缩放关节速度 |
| 奖励设计导致站立不动 | 总奖励高但速度为 0 | 加强速度跟踪，减小静态奖励，检查各项指标 |
| 鸭子只会“滑行” | 速度上去了但步态不自然 | 增加足底接触/步态项、动作平滑和摩擦测试 |
| 行走与奔跑界限不清 | 高速时仍用拖脚或跳跃 | 按课程从 `0.0~1.0` 逐步扩到 `2.0~3.5 m/s`，观察腾空比例和视频 |
