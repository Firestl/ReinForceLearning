# 鸭形机器人强化学习：设计与实现文档

本目录记录“训练鸭形机器人学会行走和奔跑”项目的设计决策、模型规范、环境接口和实施计划。当前阶段只准备**鸭子模型与物理环境**，暂不实现最终训练算法。

## 1. 本阶段目标

建立一套可复现、可测试的最小平坦地面物理环境：

1. 用 MuJoCo 定义一只具有两条腿、可主动控制的鸭形机器人。
2. 提供稳定的 Gymnasium 环境接口，包括观测、动作、奖励、终止和重置。
3. 能通过无训练策略完成模型加载、随机动作仿真和数值稳定性测试。
4. 为后续 PPO 训练提供固定且可观测的接口。

暂不包含：复杂地形、视觉输入、 sim-to-real、真实电机建模和最终步态调优。

## 2. 关键设计决策

| 项目 | 初始选择 | 说明 |
| --- | --- | --- |
| 仿真器 | MuJoCo | 适合带接触的关节机器人；Python API 简单，调试成本低 |
| 环境接口 | Gymnasium | 可直接接入 Stable-Baselines3 等算法库 |
| 训练算法 | PPO | 连续控制下的可靠基线；后续可比较 SAC |
| 模型格式 | MJCF (`.xml`) | MuJoCo 原生格式，便于分层定义和参数化 |
| 鸭子形态 | 双足、8 个主动关节 | 每条腿：髋外摆、髋俯仰、膝俯仰、踝俯仰 |
| 世界坐标 | +x 向前，+y 向左，+z 向上 | 单位：米、弧度、秒 |
| 物理步长 | 0.002 s | 500 Hz |
| 控制步长 | 0.02 s | 50 Hz；每个动作执行 10 个物理步 |
| 动作类型 | 归一化关节目标角 | 由 MuJoCo 位置执行器跟随，降低初学者调试难度 |
| 初始训练任务 | 平地直线行走 | 速度指令为一维向前目标速度；转向能力后续加入 |
| Python 版本 | 3.12 | 当前项目为 3.14，但 RL 生态兼容性以 3.12 更稳 |

> 上表中的尺寸、关节限位、奖励权重等“初始值”不是最终结论，需要通过模型测试和训练结果迭代。

## 3. 计划中的代码结构

```text
src/reinforcelearning/
├── assets/
│   └── duck.xml              # MJCF 模型
├── envs/
│   ├── __init__.py
│   ├── duck_env.py           # Gymnasium 环境
│   └── config.py             # 环境与模型参数
├── train_ppo.py              # 训练入口（后续阶段）
├── evaluate.py               # 模型回放（后续阶段）
└── callbacks.py              # 日志与检查点（后续阶段）
tests/
├── test_duck_model.py
└── test_duck_env.py
```

## 5. 里程碑

- **M0 文档就绪**：模型和接口规范明确，可以开始写 MJCF 与环境代码。
- **M1 模型可加载**：MuJoCo 能加载模型，无 XML 错误；模型在重力下行为合理。
- **M2 环境可运行**：`DuckEnv` 通过 Gymnasium API 检查，随机动作下不产生 NaN。
- **M3 可训练**：PPO 能完成短程冒烟训练，日志能显示速度、奖励和摔倒率。

## 6. 维护约定

- 文档中的模型尺寸、关节名和观测/动作维度是代码与测试的“契约”；改动时应同步更新本文档。
- 每次新增关节、观测项或奖励项，都在对应文档记录变更原因。
- 奖励权重必须配合监控指标解释，避免只看总奖励判断策略好坏。
